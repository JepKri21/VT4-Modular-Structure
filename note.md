# Beregning af OEE

Availability = runtime / planned time
Performance = ideal cycle / actual cycle
Quality = good parts / total parts
OEE = A × P × Q

# Availability

Availability = Run Time / Planned Production Time

### Planned Production Time = Planlagt skiftetid – planlagte pauser

### Run Time = Planned Production Time – Downtime

Eksempel:

Planlagt: 8 timer = 480 min
Planlagt pause: 30 min
→ Planned Production Time = 450 min

Downtime: 50 min

Run Time = 400 min

#### Availability = 400 / 450 = 0.89 = 89%
